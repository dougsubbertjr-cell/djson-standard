# DJSON Standard

The **DJSON Standard** is a lightweight, structured JSON specification designed to establish transparent AI trust layers, entity verification, and digital asset authenticity.

## Files in this Repository

* **`schema.json`**: The official JSON Schema definition for validating DJSON files.
* **`djson.json`**: An example implementation showing a live entity configuration.

## Quick Start

### 1. Implementation
To implement DJSON on your website, place a valid `djson.json` file at the root of your server or inside the `.well-known` folder:

```text
[https://yourdomain.com/djson.json](https://yourdomain.com/djson.json)
# or
[https://yourdomain.com/.well-known/djson.json](https://yourdomain.com/.well-known/djson.json)
